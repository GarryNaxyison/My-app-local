Telegram-бот NERIVA как быстрый вход в языковую практику

Telegram в NERIVA нужен для быстрого старта: открыть практику, отправить голос или фото, получить напоминание и продолжить тот же учебный профиль.

Web app - основной продукт, Telegram - быстрый companion-канал для короткой практики.

Telegram не заменяет web app

Web app удобнее для длинных уроков, тарифов, заметок и прогресса. Telegram дополняет его быстрыми задачами, голосом и уведомлениями.

Один профиль

Прогресс, Premium, ошибки, заметки и weak words должны восприниматься как одна система, а не как два разных продукта.

Что удобно делать в Telegram

Запустить короткую практику, отправить голос, добавить фото, получить напоминание или продолжить упражнение на ходу.

Что лучше делать в web app

Длинные занятия, обзор прогресса, управление тарифом, словарь ошибок и спокойный разбор материала лучше работают на большом экране.

Почему блок уехал с главной

На главной остались две кнопки входа. Подробное сравнение Web app и Telegram вынесено сюда, чтобы не перегружать первый экран.

Вопросы и ответы

Можно заниматься только в Telegram?

Да, короткая практика доступна в Telegram, но web app удобнее для длинных занятий и управления профилем.

Прогресс синхронизируется?

Да. Идея NERIVA - один учебный профиль для web app и Telegram.

Что можно отправлять в Telegram?

Текст, голосовые ответы и фото для перевода или практики по контексту.

Telegram обязателен?

Нет. Можно начинать с web app. Telegram остается быстрым дополнительным каналом.

Есть ли платные функции?

Да. Free, Premium и Platinum отличаются дневными лимитами и доступом к голосовым и фото-инструментам.
