Questions and answers

What is included in the web app?

Lessons, practice, pronunciation, notes, mistakes, progress, plans, and user profile tools.

How is the web app different from Telegram?

The web app is better for longer sessions, progress, pricing, and profile control. Telegram is faster for short tasks.

Can I learn languages beyond English?

The interface supports multiple languages, while the first SEO wave focuses on English search demand.

Are there paid plans?

Yes. Free, Premium, and Platinum provide different daily limits and access to voice and photo tools.

Do I need to install an app?

You can use it in a browser. On mobile, the web app works as a mobile page or PWA-style experience.
