# Деплой NERIVA через постоянный upload-сервис

Сохранять аккаунты, учебные сессии, XP, изученные слова, ошибки и настройки. Старый скрипт полного деплоя удалён.

- Штатный upload endpoint — `https://poliglotai.online/__codex_deploy_upload/<filename>`. Проверка — `https://poliglotai.online/__codex_deploy_upload/healthz`.
- Служба — `poliglot-deploy-upload.service`. Учётные данные использовать только в памяти текущего процесса. Не выводить их в логи.
- Для веб-выпуска загружать только текущие JS/CSS, HTML и service worker. Проверить размер и SHA-256 пакета. Сначала установить ассеты, затем атомарно заменить HTML. Сервер приложения при этом продолжает работать.
- Если выпуск включает бэкенд, собрать Linux-бинарник из проверенного коммита, проверить миграции, загрузить бинарник через тот же upload-сервис и сверить SHA-256. Заменить бинарник атомарно и перезапустить только службу приложения. Сверить записи прогресса до и после в режиме чтения.
- Во время деплоя не менять `.env`, содержимое пользовательских баз или словари и не создавать резервные копии. Удаление прогресса при запуске приложения запрещено.
- После выпуска проверить `/healthz`, `/app/` и `/neriva.html` на `https://neriva.ru`. Сверить опубликованные JS/CSS с артефактами выпуска.
