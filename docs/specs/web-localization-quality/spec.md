# Качество переводов интерфейса NERIVA

Дата: 2026-11-17.

В веб-приложении поддерживаются 35 языков интерфейса. Публичный сайт по-прежнему предлагает русский и английский. Цель проверки — отличать техническое наличие текста от полноценного перевода. Например, немецкая подсказка о повторении урока раньше сокращалась до `Lektion`, японская — до `レッスン`. В обоих случаях пропадало указание повторить фразу завтра.

Для каждого языка подготовлены отдельные формулировки двух подсказок о повторении, заголовка с материалом для повторения и сообщения об ошибке запроса. Критерии: строки разрешаются в выбранной локали и сохраняют смысл, региональный код ведёт в подходящий словарь, навигационные подписи не состоят из знаков препинания и не повторяют заголовки. Язык документа синхронизируется с языком интерфейса для средств чтения с экрана.

Полная редактура словарей остаётся открытой. Базовый веб-словарь содержит около 450 ключей. Сравнение вывода с общим механизмом подстановок выявляет кандидатов для проверки, но совпадение не доказывает ошибку, особенно у коротких навигационных меток. Последующие проверки следует вести по сценариям: вход и восстановление доступа, обучение, инструменты, оплата, настройки и справка. Утверждать качество всех текстов можно после редакторской проверки этих сценариев в каждом языке.

Проверка Telegram охватывает меню и переход в веб-приложение, язык интерфейса, уроки AI-репетитора, аудиозадания и авторизацию кодом через тесты Go. Кнопка «Веб-версия» использует обычную ссылку Telegram. Проверка интерфейса внутри клиента на реальном устройстве проводится отдельно.
