# Повторная отработка произношения

Из разбора можно открыть отработку первого слова с отмеченным звуком или первой проблемной позиции. В поле задания появляется это слово, доступен образец и можно отправить отдельную запись. При смене задания сравнение двух оценок сбрасывается.

Если измеренная уверенность распознавания по logprobs ниже 0,45, веб-раздел просит перезаписать фразу. Такой результат исключён из итогового отчёта, локальной истории и сравнения. Оценки с другими источниками уверенности обрабатываются по прежним правилам. Порог выбран для первого выпуска и проверен на тестовых ответах API.

Перед записью или загрузкой аудио, в том числе в уроке, практике, ролевой сцене и «Голос в текст», отображается остаток общей дневной квоты из полей профиля `voice_limit` и `voice_today`. Остаток не опускается ниже нуля. При отсутствии числовых данных подпись скрыта.
