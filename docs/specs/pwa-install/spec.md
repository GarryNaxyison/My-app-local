# Установка и повторная загрузка NERIVA

Дата: 2026-11-17.

На главной сайта есть компактная ссылка установки на русском и английском. Ссылка ведёт в веб-приложение. Поддерживаемый браузер открывает системную установку по нажатию. На iPhone и iPad показываются шаги через меню «Поделиться». Для прочих браузеров доступна ручная инструкция. Плашку можно закрыть клавишей Escape или кнопкой, действие доступно при входе в аккаунт.

Сервис-воркер хранит одну общую страницу запуска и необходимые файлы интерфейса с версионными именами. При повторном входе эти файлы обслуживаются из кеша. HTML сначала запрашивается по сети. Кешированная копия доступна при потере связи, когда необходимые для неё файлы уже сохранены. Запросы API, персональные данные и параметры URL в кеш интерфейса не попадают. Установка новой версии не перезагружает активный урок или несохранённый ответ. Для входа и синхронизации требуется интернет.

Критерии проверки: русская и английская ссылки, браузерная установка и ручная подсказка, возврат при отсутствии сети, повторная выдача файлов из кеша, отсутствие записей API в кеше. На мобильном сохраняются видимый первый экран и области касания от 44 пикселей у проверяемых действий. Карточки возможностей и мобильных сценариев поддерживают управление стрелками и видимый фокус.
