# Очередь повторений NERIVA

## Цель

Дать ученику одно место для просмотра и выполнения повторений из уроков, AI-репетитора и ролевой практики. Первый этап предоставляет чтение расписания AI-репетитора из действующих хранилищ.

## Первый этап

- Авторизованный `GET /api/learning-reviews` возвращает объект `items` с массивом записей текущего аккаунта и языка обучения. У записи есть стабильный идентификатор, источник, идентификатор урока, заголовок, срок в UTC и состояние `due` или `upcoming`. Пустая очередь возвращает пустой массив.
- Срок сравнивается с серверным временем. Сначала идут самые ранние сроки, записи с одним сроком сортируются по идентификатору.
- Для одного урока используется последняя валидная запись расписания. При совпадении времени обновления применяется более ранний срок, затем идентификатор записи.
- Записи с неизвестным уроком или недействительным сроком пропускаются. Действующее сохранение расписания одинаково используется в вебе и Telegram. Схема базы и прежние маршруты остаются доступны.

## Критерии

Проверить выдачу просроченного и будущего уроков, фильтрацию по аккаунту и языку, дубли старых записей и HTTP 401 для гостя. Проверить существующие тесты AI-репетитора и SQLite.

## Экран «Сегодня»

На экране «Сегодня» выводится первое повторение AI-репетитора из очереди. Срок отображается в часовом поясе устройства. По наступившему сроку пользователь с Premium может открыть конкретный урок существующим маршрутом повторного запуска. При активном уроке в текущем веб-приложении кнопка повторения отключена. Будущий срок показан без кнопки запуска. Если сервер недоступен или очередь пуста, блок не отображается.

## Следующие этапы

Запуск пока не завершает запись в очереди. Следующий этап — отдельный контракт записи результата с идемпотентным идентификатором попытки и подключение ошибок обычного урока и ролевой практики.
