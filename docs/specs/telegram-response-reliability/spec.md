# Надёжность ответов Telegram

## Цель
Восстановить ответы Telegram-бота на действия и короткие запросы к ИИ.

## Объём и поведение
Читать успешный результат Telegram как объект сообщения или `true`. Сохранять ID отправленного сообщения. Для текстовых запросов `openai/gpt-6` отключать рассуждения, чтобы короткий лимит не расходовался на скрытые токены. Политику остальных моделей сохранять.

## Ограничения
Не менять серверные настройки, пользовательские базы, прогресс и веб-ассеты. Не создавать резервные копии.

## Критерии и проверки
- Регрессии Telegram проверяют `true` для четырёх методов и объект сообщения с ID.
- Регрессия OpenRouter проверяет отключение рассуждений GPT-6 и сохранение настроек другой модели.
- Выполняется `go test ./... -count=1`, собирается Linux-бинарник.
- При публикации сверяются SHA-256, состояние службы, HTTP health и количества записей прогресса в SQLite.
- Проверка настоящего пользовательского диалога требует ответа пользователя; HTTP health не доказывает работу всех диалогов.
