# Маршрут «Поездка»

Пилот на экране «Сегодня» доступен авторизованным ученикам, которые изучают английский с русским интерфейсом. Три последовательных задания охватывают отель, вокзал и ресторан. Ошибка оставляет ученика на текущем задании. После завершения доступны повтор маршрута, переход в каталог ролевых сцен и печать трёх карточек.

Прогресс хранится до ухода с экрана. Пилот не начисляет XP. Выбор темы по метрикам и сравнение завершения с общим маршрутом требуют отдельного замера.

Проверка: неверный ответ не продвигает маршрут, три верных ответа открывают печать и переход в ролевые сцены.
