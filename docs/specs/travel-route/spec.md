# Маршрут «Поездка»

После трёх заданий можно отдельно повторить слова маршрута. Сначала виден русский перевод, затем по кнопке открываются английское слово и пример. Кнопка перехода к следующему слову снова скрывает ответ.

Пилот на экране «Сегодня» доступен авторизованным ученикам, которые изучают английский с русским интерфейсом. Три последовательных задания охватывают отель, вокзал и ресторан. Ошибка оставляет ученика на текущем задании. После завершения доступны повтор маршрута, переход в каталог ролевых сцен и печать трёх карточек.

Прогресс сохраняется в браузере отдельно для каждого аккаунта и восстанавливается после перезагрузки. Кнопка повтора сбрасывает сохранённый шаг. Между устройствами прогресс не синхронизируется. Пилот не начисляет XP. Выбор темы по метрикам и сравнение завершения с общим маршрутом требуют отдельного замера.

Проверка: неверный ответ не продвигает маршрут, три верных ответа открывают печать и переход в ролевые сцены.
