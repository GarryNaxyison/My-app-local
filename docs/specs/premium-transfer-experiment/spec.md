# Эксперимент Premium после упражнения

Цель — измерить эффект предложения после успешного самостоятельного повтора. При выключенном флаге действует текущий интерфейс. При включённом флаге бесплатный аккаунт стабильно получает одну из двух групп. Контроль видит результат упражнения, тестовая группа также видит предложение Premium. Обычный экран тарифов доступен обеим группам.

В выборку входят аккаунты после первого сохранённого повтора при включённом флаге. Повторный запрос не добавляет участника второй раз. Для сравнения нужны подтверждённые оплаты, завершение занятий, активность на седьмой день и стоимость голосовых проверок. Сам факт распределения не подтверждает просмотр предложения. До проверки этих событий и настройки отчёта флаг должен оставаться выключенным.

Приёмка первого этапа: стабильное деление аккаунтов, исключение платных пользователей, сохранение существующего поведения с выключенным флагом, отсутствие предложения в контроле, отсутствие персональных данных в ответе о группе.

Событие первой покупки записывается после подтверждённой оплаты Telegram Stars или ЮKassa и успешной активации. Отчёт `python tools/premium-transfer-report.py <путь-к-SQLite>` открывает базу в режиме чтения и показывает агрегаты для двух групп. Он включает аккаунты с восемью сутками наблюдения, покупки в первые семь суток и активность в интервале от семи до восьми суток. Счётчик голосовых повторов показывает зарегистрированные повторные отправки. Для оценки стоимости и доли завершённых бесплатных занятий нужны отдельные события.
