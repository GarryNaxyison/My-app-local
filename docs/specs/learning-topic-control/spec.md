# Тема обучения в верхней панели

В общей панели рядом с языком и оформлением пользователь может открыть окно выбора темы, выбрать готовый вариант, указать свой или очистить предпочтение пунктом «Разные темы». На телефоне кнопка доступна в верхних быстрых действиях на «Сегодня» и в AI Репетиторе.

Сохранение использует поле профиля `learning_focus` через существующий API настроек. Оно влияет на последующие уроки и практику. Текущий урок не перезапускается. При открытии отображается сохранённое значение. При ошибке окно остаётся открытым.

Подписи окна покрывают 35 языков веб-интерфейса. Для готовых тем используются локализованные названия из каталога сценариев. Арабская версия окна поддерживает направление справа налево.
