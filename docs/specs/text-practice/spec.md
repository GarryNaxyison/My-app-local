# Практика из своего текста

В разделе «Практика» ученик вставляет до 1200 символов и выбирает один из двух вопросов, составленных по тексту с учётом языка интерфейса и уровня. При недоступности генерации остаются шаблоны на главную мысль и важную деталь. При проверке текст, вопрос и ответ передаются через обычный маршрут практики с его лимитами и историей.

Пустой и слишком длинный текст блокирует подготовку вопросов. При ошибке проверки введённый ответ сохраняется на экране.

Генерация также предлагает до шести слов или выражений из текста с переводом. Сервер отбрасывает отсутствующие в тексте слова и дубликаты. Кнопка печати открывает общий шаблон NERIVA с возможностью исключить отдельные карточки.

Критерий приёмки: браузерный тест проверяет ограничения ввода, вопрос, передачу контекста, вывод ответа API, предпросмотр карточек и готовые вопросы при сбое.
