# Офлайн-повторение

Обновление колоды сохраняет до 100 карточек с ответом для текущего аккаунта. Офлайн-экран показывает карточку, позволяет открыть ответ и отметить, удалось ли его вспомнить. Отметки о знакомых карточках сохраняются между перезагрузками. Успешный выход из аккаунта отключает доступ к его колоде с офлайн-экрана.

Проверки: обновление колоды под авторизованным аккаунтом, открытие закэшированного приложения в Chromium без сети, скрытие ответа до раскрытия, сохранение отметки после перезагрузки.

Синхронизация отметок с профилем остаётся отдельной задачей. Офлайн-экран рассчитан на ранее загруженную оболочку приложения и локально сохранённую колоду.
