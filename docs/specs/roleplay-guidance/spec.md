# Цель и подсказки ролевой сцены

В английской сцене «Ресторан» ученик видит цель заказа блюда. Первая подсказка раскрывает начало фразы, вторая показывает полный пример. Состояние подсказок сбрасывается при старте сцены.

Пилот проверяет отправленные текстовые реплики после успешного ответа сервера. Поддерживаемые формулировки заказа блюда закрывают цель до смены сцены. Просьба принести меню предлагает повторить попытку. Голосовые записи в проверку цели не входят.

Критерии приёмки: на ПК и телефоне видна цель, пример появляется после второй кнопки, просьба принести меню не закрывает цель, заказ супа закрывает цель.
